СТЕК — Вайбкодер-аутричер / Polza Agency
=========================================

IDE / окружение
---------------
Claude.ai  — основная среда (Claude Code / computer-use sandbox)
VS Code    — локальное редактирование и тестирование скриптов

Модели
------
claude-sonnet-4-20250514  — сбор лидов, персонализация, генерация писем
  └─ tool: web_search_20250305  — поиск актуальных данных о компаниях

Языки и библиотеки
------------------
Python 3.12
  anthropic   — Python SDK для Claude API
  openpyxl    — создание / редактирование xlsx
  argparse    — CLI-аргументы для скриптов

Инструменты сбора базы
----------------------
Ручной seed (51 компания) — реальные российские B2B-компании из
публичных источников (сайты, LinkedIn, 2ГИС, Spark-Interfax).
collect_leads.py + Claude web_search — автоматическое расширение базы
по любому сегменту.

Процесс
-------
1. build_deliverable.py  → polza_leads.xlsx (база + цепочка писем)
2. personalize.py        → заполняет столбец «Персонализация» через Claude
3. collect_leads.py      → докидывает новые лиды в xlsx по нужному сегменту

Время выполнения задания: ~3 часа
